# АІС «Пожежна частина»

Курсова робота з дисципліни «Бази даних»: автоматизована інформаційна система пожежної частини.

Go + MS Access (.accdb через ODBC) + повноекранний TUI (Bubble Tea) + ШІ-асистент (aimlapi) + PDF-звіти.

## Можливості

- **Повноекранний TUI** — запуск exe подвійним кліком; сторінки-вкладки, все на одному екрані
- **Сторінка «Огляд»** — дашборд: викликів усього/сьогодні, активний склад, техніка в строю, останні виклики
- **Сторінка «Таблиці»** — браузер усіх 12 таблиць зі скролом
- **Сторінка «Новий виклик»** — форма реєстрації (власний компонент на bubbles/textinput)
- **Сторінка «Звіти»** — PDF «Виклики за період» у папку `reports/` поруч з exe
- **Сторінка «AI-асистент»** — запит українською → SQL (Access) → таблиця результатів (лише SELECT)
- **Сторінка «Налаштування»** — шлях БД, шрифт, ключ ШІ; конфіг `~/.fire-station/config.yaml` (0600)
- **БД у файлі Access** — `data/fire_station.accdb` поруч з exe; відкривається в MS Access

## Палітра

Монохром (білий/сірий). Колір — лише для семантики станів:
зелений — «в строю»/«завершений», жовтий — «в роботі»/«ремонт», червоний — помилки/«новий» виклик.
Вибрані елементи — інверсія кольорів.

## Керування

```
1–6      — перехід на сторінку
← / →    — перемикання сторінок / опцій у полях-перемикачах
↑ / ↓    — навігація списками, таблицями, полями форми
tab      — наступне поле форми
enter    — відкрити таблицю / підтвердити поле (на останньому — зберегти)
esc      — назад / скасувати форму
r        — оновити статистику на сторінці «Огляд»
q        — вихід (ctrl+c — завжди)
```

## Вимоги (одноразово)

1. Go 1.22+
2. MinGW-w64 (gcc) — ODBC потребує cgo. Наприклад через Scoop: `scoop install mingw`
3. Microsoft Access Database Engine 2016 (або встановлений Office з Access)
4. Шрифт `DejaVuSans.ttf` у `assets/fonts/` (для кирилиці в PDF)

## Збірка та запуск

```powershell
go mod tidy
go build -o fire-station.exe .
./fire-station.exe   # або подвійний клік
```

Першим запуском програма сама створить `data/fire_station.accdb` поруч з exe, схему (12 таблиць) і демо-дані.

## Структура

```
cmd/
  tui/          Повноекранний TUI: сторінки, дашборд, власні форми, таблиці
internal/
  db/           ODBC-підключення до .accdb, схема, демо-дані, запити, статистика
  report/       Генерація PDF (gofpdf)
  ai/           Клієнт aimlapi: NL→SQL з політикою безпеки
  config/       Конфіг користувача (0600)
assets/fonts/   Сюди покласти DejaVuSans.ttf
data/           Файл БД (створюється автоматично поруч з exe)
reports/        Згенеровані PDF (поруч з exe)
```

## Модель даних (12 таблиць)

positions, shifts, employees, employee_shifts, equipment, equipment_checks,
fire_types, calls, dispatches, dispatch_crew, dispatch_equipment, damages

Деталі — `internal/db/schema.go`.
